# media

Sound files for `buffer~ name file`, served at `/media/<file>`. Use wav, mp3,
m4a or aiff: every phone browser decodes these (iOS Safari does not decode
ogg). Stereo is mixed to mono. File names: letters, digits, `.`, `_`, `-`.
Phones load a patch's files before it starts, so keep them short.

`test-phrase.wav` is generated by `deno task media` (media-assets.ts).
